WPS Image Compat for Excel

Version 0.8 detects DISPIMG formulas, reads WPS image resources, and displays removable PNG/JPEG previews while keeping original formulas.

Image previews require ExcelApi 1.10. Use Refresh after resizing cells, or Remove Preview Images to remove plugin pictures. Saved workbooks retain preview shapes.

Convert Workbook is deliberate and requires a confirmation. It creates a permanent Shape for every successfully resolved DISPIMG image, then clears only that converted formula. Optional formula conversion freezes the current non-error value of selected unsupported or external-link formulas; it never guesses a broken #REF! target.

Check Compatibility reads formula errors, compatibility markers, external references and the date system without changing cells. Detailed reports include business content and download locally. External targets, defined names, connections, charts, macros and layout are not validated.

For development, run the local HTTPS server, trust its certificate, then load manifest.xml inside Excel.
