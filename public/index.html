WPS Image Compat for Excel

在 Windows 和 macOS 桌面版 Excel 中扫描 WPS DISPIMG 公式，显示可移除的 PNG/JPEG 图片预览，并保留原始公式。

下载 Excel 加载项清单

这是供 Excel 安装的 XML 清单。网站本身不能读取工作簿；安装后无需运行本地开发服务。

WPS 表格安装

Windows 或 Linux 上已安装 WPS 表格时，请打开专用的 WPS 加载项安装页，启用 wps-image-compat-et 后重新打开 WPS 表格。它与上方 Excel 清单相互独立。

WPS 工具箱只读扫描 DISPIMG 公式和 WPS 可公开读取的普通图片位置，不会修改当前工作簿。WPS 的图片置入单元格接口尚未完成跨版本验证。

macOS 安装

  1. 下载上方清单，将它保存到 ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/。目录不存在时先创建。
  2. 保存工作并完全退出、重新打开 Excel，从「开始 → 加载项」菜单选择本插件。部分旧版界面使用「插入」下的加载项菜单，请以实际界面为准。侧载插件不一定出现在账户/商店的「我的加载项」窗口中，也不属于「开发工具 → Excel 加载项」。
  3. 打开工作簿，从「插入 → 图片兼容 → WPS 图片工具」打开任务窗格，先 Scan Workbook，再 Show Images。

Windows 安装

测试时，将清单放入共享目录，通过 Excel「信任中心 → 受信任的加载项目录」添加共享目录，再从「我的加载项 → 共享文件夹」安装。企业也可由 Microsoft 365 管理员统一部署。

使用说明

新版“检查兼容性”按问题类型汇总，并可定位到首个匹配单元格。它只读检查公式错误、兼容标记、外部引用和日期系统；详细报告包含公式等业务内容，仅在本地下载，不会上传。未完成的检查会明确标注；这不是一键修复所有 WPS/Excel 差异。

本页下载的是线上生产清单，任务窗格将从本站加载并检查后续更新。若此前安装了 localhost 开发版，请用此文件替换后完全退出并重开 Excel。

任务窗格支持简体中文和英文，自动跟随 Excel，也可手动切换。发布新版后会提示更新；正在处理图片时不会强制刷新。首次从旧版升级，请关闭并重新打开任务窗格。

图片操作需要 ExcelApi 1.10。Show 显示预览，Refresh 重新适配单元格，Remove Preview Images 仅清理插件标记预览。Convert 需先确认：已找到的 DISPIMG 会转换为永久 Excel 图片并清除成功转换的公式；可选择把当前非错误的外部/不支持公式结果冻结为值。#REF! 不会被自动猜测或改写。

请先用文件副本测试。真实 WPS 文件兼容性及 Windows/macOS 显示效果仍需验收；如果 Excel 已丢弃 WPS 图片资源，插件无法恢复不存在的资源。
